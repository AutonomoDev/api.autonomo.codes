Autonomo AI API Documentation

Welcome to the API documentation for Autonomo AI's Digital Partner services. This API allows you to interact with volunteer sign-ups and system health checks.

Health Check

GET /api/health

Description: Checks the operational status of the Autonomo AI API.

Response (200 OK):

{
  "status": "healthy",
  "service": "Digital Partner Backup",
  "timestamp": "2023-10-27T12:00:00+00:00"
}

Volunteer Sign Up

POST /ai-companion/signup

Description: Submits a new application for the Autonomo AI volunteer tester program.

Request Body (JSON):

{
  "fullName": "Jane Doe",
  "email": "jane.doe@example.com",
  "country": "Canada",
  "aiPlatforms": "Character.AI, Replika, Poe",
  "experience": "over-year",
  "motivation": "I believe in the importance of digital relationships and want to help ensure they are portable and respected.",
  "technicalSkills": "Frontend development, QA testing",
  "consent": true,
  "newsletter": true,
  "timestamp": "2023-10-27T10:00:00.000Z"
}

Parameters:

  • fullName (String): The full name of the applicant. Required
  • email (String): The applicant's email address. Required
  • country (String): The applicant's country of residence. Required
  • aiPlatforms (String): AI companion platforms used (e.g., "Character.AI, Replika"). Required
  • experience (String): Duration with AI companion. Options: "less-than-month", "1-6-months", "6-12-months", "over-year". Use empty string "" for "Please select". Optional
  • motivation (String): Reason for interest in the project. Minimum 20 characters. Required
  • technicalSkills (String): Applicant's technical background. Optional
  • consent (Boolean): Must be true to agree to terms. Required
  • newsletter (Boolean): Set to true to opt-in for updates. Optional
  • timestamp (String): ISO 8601 format timestamp of submission initiation (e.g., "2023-10-27T10:00:00Z"). Required

Responses:

200 OK: Successful submission.

{
  "success": true,
  "message": "Thank you for volunteering! We'll contact you soon.",
  "registrationId": "20231027120000_abcdef12"
}

400 Bad Request: Invalid input, missing required fields, or consent is false.

{
  "success": false,
  "errors": {
    "email": "Please provide a valid email address",
    "consent": "You must agree to the terms to participate"
  },
  "message": "Please correct the errors and try again."
}

500 Internal Server Error: Server error during processing.

{
  "success": false,
  "message": "An error occurred during registration. Please try again later."
}
